# Warriors Dream Series — Homepage

A single self-contained `index.html` — no build step, no dependencies.
Everything (styles, fonts, and interactivity: the live countdown, the
past-events filter, the testimonial carousel) lives inline in that one file.

## Deploy

Hosted via GitHub Pages, serving straight from the repo root:
**Settings → Pages → Source: Deploy from a branch → `main` / `(root)`**

To update the site, edit `index.html` and push — no build or install step.
